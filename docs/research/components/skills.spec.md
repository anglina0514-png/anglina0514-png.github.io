# Skills Specification

## Overview
- Target: `#about` skill marquee, capability evidence and experience evidence.
- Interaction model: time driven marquee with scroll velocity bias.

## Structure
- Four full-width ticker rows, no card frame.
- Row categories: AI visual, content growth, UE/Blender/Web, research/product.
- Category colors follow design tokens.
- Compact evidence matrix follows the ticker; it must not compete with the first skill viewport.

## Responsive
- Desktop: 3-4 rows, 44-72 px tokens.
- Mobile: 4 rows, 28-42 px tokens, clipped cleanly at viewport edges.

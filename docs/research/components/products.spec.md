# Products Specification

## Overview
- Target: `#products` and `.product-showcase`.
- Interaction model: scroll stage + click/open.

## Structure
- Three entries: 知投学堂, 防网贷视觉游戏, AI + UE Visual.
- Active entry is large and inspectable; adjacent entries remain at the boundary.
- Homepage card shows cover, title and concise description only.
- UE subworks remain inside the existing modal, including four playable media items.

## Responsive
- Desktop: horizontal scene with one active 60-68vw panel.
- Mobile: vertical one-panel-per-view sequence, no overlapping vertical text.
